品牌简介

云帆是面向个人与团队的网络加速服务，核心是机场订阅与客户端导入。用户按套餐获取专属订阅地址，在常用工具中更新配置后即可切换全球节点，用于浏览、流媒体、协作与游戏加速。

我们强调线路质量与日常可用性：普通节点覆盖常用地区，旗舰与团队线路加入游戏优化与更高带宽资源。官方身份仅以本站公布的套餐与说明为准，避免通过来路不明的渠道获取所谓“官网下载”。

服务原则

订阅即配置，不捆绑来源不明的安装包。客户端请从各工具原作者或可信开源渠道获取，云帆只提供订阅与节点策略说明。

基础版面向轻度使用，旗舰版面向流媒体与游戏，团队版面向多设备与定制路由。流量按自然月计算，设备数按套餐上限同时在线。

使用场景

流媒体与内容访问

旗舰版与团队版侧重原生解锁能力，适合连续观看常见海外平台。若遇个别节目限制，可在客户端中更换同区域节点后重试，无需反复重装软件。

游戏与实时应用

游戏加速依赖专线与低抖动节点。旗舰版标注的 IPLC 优化更适合对延迟敏感的对战与下载；团队版额外提供高带宽 VIP 节点，便于多人同时在线。

远程办公与协作

访问海外文档、代码仓库与会议工具时，稳定比单纯“跑分”更重要。建议固定一条质量较好的线路，并在客户端开启规则分流，让国内站点直连。

多设备家庭或小团队

按同时在线台数选择套餐，手机、电脑与电视盒子可共用同一订阅。超出上限时优先下线闲置设备，或升级到团队版并划分成员路由。

客户端选择与官网下载指引

云帆机场订阅兼容主流代理客户端。本站强调“客户端选择”：先选对工具，再导入订阅，而不是寻找来路不明的一体包。下列说明帮助您按系统完成官方下载与配置。

Windows

常用 Clash Verge 或 v2rayN。从项目发布页获取安装包，打开后进入订阅栏，粘贴云帆提供的订阅地址并更新。连接前先选规则模式，避免全局干扰国内网站。

macOS

可选 ClashX Meta 或 Surge。导入订阅后检查系统代理是否被正确接管。若仅需浏览器加速，可搭配系统或浏览器分流，减少无关应用走代理。

Android

推荐 Clash Meta for Android 或 v2rayNG。安装后允许 VPN 权限，添加订阅并更新节点列表。移动网络与 Wi-Fi 切换后如未自动重连，在客户端内手动开启即可。

iOS

常用 Shadowrocket、Stash 或 Quantumult X（需自行在应用商店获取）。导入订阅后建议开启分流规则。iOS 对后台 VPN 较严格，锁屏较久后重新点一次连接属正常现象。

Linux 与其它

可使用 clash 核心或兼容内核，配合配置文件或订阅转换。命令行用户注意权限与开机自启，避免把订阅明文提交到公开仓库。

操作说明

从订阅到连上的步骤

  1. 在套餐中选定档位，完成订阅后复制专属链接（请勿公开分享）。
  2. 根据上一节下载对应客户端，仅使用可信发布来源。
  3. 在客户端添加订阅、更新节点，选择靠近目标站点的线路。
  4. 先用规则模式测试网页与应用，确认国内流量未全部走代理。
  5. 流媒体或游戏若异常，切换同区域其它节点，或改用旗舰/团队中的优化线路。

日常维护

节点会不定期调整，客户端内定期更新订阅即可。流量将尽时提前升级，避免高峰被限速。设备更换后删除旧配置，防止订阅泄露后被他人占用在线名额。

节点与性能说明

云帆节点覆盖香港、日本、新加坡、美国、台湾及部分欧洲入口，普通池满足浏览与轻度视频，旗舰增加原生解锁与游戏向专线，团队版提供更高带宽的 VIP 入口。

实际速度受本地宽带、时段与目标站点影响。我们不公布虚构评分，建议以您常用应用实测：打开目标网站或游戏，观察延迟与缓冲。工单优先处理旗舰与团队用户的线路异常。

常见问题

如何获取云帆订阅并在客户端里使用？

完成套餐后即可复制专属订阅地址。打开已安装的客户端，进入订阅或配置页面粘贴该地址并更新，随后选择节点连接。链接等同账号凭证，不要发到群组或网盘。

各套餐同时在线设备数如何理解？

基础版 3 台、旗舰版 5 台、团队版 20 台，按同时建立的代理连接计算。手机与电脑同时开着即占用两台。超限时请先断开闲置设备，或升级档位。

能否解锁常见流媒体？基础版和旗舰版差别大吗？

基础版覆盖部分基础平台，旗舰与团队强调全节点原生解锁。若某部影片仍提示地区限制，请更换同区域节点并清除应用缓存后再试。

游戏加速是否包含 IPLC？适合哪些用户？

旗舰版包含 IPLC 专线游戏优化，适合对延迟敏感的对战与更新下载。团队版另有 VIP 高带宽节点。休闲网页游戏通常普通节点即可。

流量用尽后会立刻停网吗？怎样升级？

当月额度用完后可能限速或暂停加速，次月重置。可补差价升级到更高档位。未用完流量一般不结转，请按实际用量选档，避免长期闲置大流量套餐。

云帆官网提供客户端安装包下载吗？

不提供第三方客户端打包，以免被仿冒站点夹带不明程序。请自行前往各客户端官方或开源发布页下载，再仅导入云帆订阅。这是本站强调客户端选择的原因。

新用户是否支持退款？工单如何联系？

短期内几乎未使用且符合规则的订单可申请协商退款，具体以工单答复为准。旗舰版享有优先工单，团队版配备客户经理跟进定制路由需求。
